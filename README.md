# Playwright Automation Framework (Python)

## 🚀 Overview
This project demonstrates Playwright automation using Python with pytest.

##  Features
- UI Automation (Playwright)
- API Testing (APIRequestContext)
- Data-Driven Testing (pytest parametrize)
- Modular framework structure
- Reusable utilities

##  Project Structure
- tests/ → Test cases
- utils/ → API utilities
- test_data/ → Data-driven inputs

## Run Tests
```bash
pytest -v -s
